## 5. 実装の中心と優先レビュー項目

手法は、ACDI界面捕獲を伴う非圧縮性二相流計算を、EPPの弱圧縮性サブステップで補助するもの。
小ステップの流束・表面張力を時間積分し、主ステップの初期状態から更新を再構成して非圧縮性圧力補正を行う。
弱圧縮性計算の最終速度をそのまま主ステップの予測速度にする処理とは異なる。

| レビュー対象 | 確認する内容 |
|---|---|
| ACDI | 相流束の符号、Gamma、界面厚さ、psiのlog、相分率の保存 |
| 運動量輸送 | 相流束から作る質量流束との整合、WENO3と粘性応力 |
| 表面張力 | 法線・曲率の符号、面での評価、圧力勾配との釣合い |
| EPP | 圧力更新の符号・密度・時間刻み、10回反復、人工音速 |
| 主ステップ | 流束発散と力の積算、最後の密度での除算、単一substep時の標準法との一致 |
| 壁面 | 側面free-slip、上下no-slip、重力と壁面圧力補正の整合 |
| 圧力解法 | 零平均の拘束、真の残差、非収束時の停止、投影後の速度発散 |

付録Aの式36は、表示上、右辺の `1/dt` が欠けている。現行コードは本文2.2節・次元・速度補正式に従い、
`div(grad(p)/rho_face) = div(u_star)/dt` を採用している。著者確認済みの訂正ではないので、この判断を記録する。
曲率は法線の発散の負値というスカラー量として実装した。

論文との差または未確定点は以下。結果に合うよう黙って調整せず、根拠と感度を残す。

- 圧力ソルバーは論文のhypre FlexGMRES/PFMGではなく、Jacobi前処理PCG。停止ノルムも同一ではない。
- Gammaに使う速度は `hypot(max(abs(uf)), max(abs(vf)))` という上界。各成分の最大位置が違えば、最大速度大きさより大きくなる。
- 初期界面は `0.5*(1+tanh((r-R)/(2*epsilon)))`、`epsilon=dx`。ACDIから推定した選択。
- WENO-JS3の微小定数等は実装上の選択。風上判定に面速度を使っている。
- 重力を面力 `rho_face*g` として積算する点と、壁面の圧力条件の扱いを要検証。
- 輸送した相分率の強制クリップはしていない。log計算時だけクリップする。非物理値を隠す修正はしない。
- 配列の生成・複製が多いCPU向け初期版。並列化・GPU化・マルチグリッドによる高速化は未実施。

単体テストには単相静水圧と曲率の検査があるが、それだけで二相界面の力の釣合いを保証できない。
静止円形気泡を別途作り、2DのLaplace圧力差 `sigma/R`、寄生流、密度比と格子依存性を検査する。

## 6. 4.2節：気泡上昇の条件と実行

出典：論文4.2節と図5。相分率は `phi=0` が気体、`phi=1` が液体。

| 項目 | 条件 |
|---|---|
| 領域 | 10 mm × 20 mm |
| 格子 | 256 × 512、dx=dy=3.90625e-5 m |
| 気泡 | 直径2.5 mm、中心(5,5) mm |
| 密度：液体／気体 | 998／1.2 kg/m³ |
| 粘度：液体／気体 | 1e-3／1.8e-5 Pa·s |
| 表面張力 | 0.072 N/m |
| 重力 | (0,-9.8) m/s² |
| 初期速度・圧力 | いずれも0 |
| 左右境界 | free-slip |
| 上下境界 | no-slip |
| 図5比較範囲 | 0～0.07 s |
| 提案法の主時間刻み | 30 × 毛管時間刻み |

毛管時間刻みは `sqrt((rho_g+rho_l)*dx^3/(4*pi*sigma))` で、約8.113254e-6 s。
粘性制約は約2.543132e-5 s。substepでは論文の他の制約と係数も適用される。
0.07 sは毛管時間刻み約8,628個分であり、瞬時に終わるテストではない。

小規模検証後の本計算コマンド：

```bash
julia --project=. scripts/run_bubble.jl standard 256 1 0.07 results/bubble-standard
julia --project=. scripts/run_bubble.jl weak 256 1 0.07 results/bubble-weak
julia --project=. scripts/run_bubble.jl subcycling 256 30 0.07 results/bubble-proposed
julia --project=. scripts/compare_bubble.jl results/bubble-standard reference/bubble_standard.csv reference/bubble_standard.toml results/standard-comparison.toml
julia --project=. scripts/compare_bubble.jl results/bubble-proposed reference/bubble_standard.csv reference/bubble_standard.toml results/proposed-comparison.toml
```

気泡上昇速度は `sum((1-phi).*v)/sum(1-phi)`。3方式の時間履歴を論文の対応曲線へ重ねる。
提案法と自作標準法の相互比較だけでは、共通の誤りを見逃すので不十分。
初期圧力変化によるEPP単独の振動と、提案法でのその抑制も確認する。
方式の一つだけ静水圧で初期化して論文の起動条件を変えない。

`history.csv` は各主ステップで出力される。`field_*.vtk` は場のスナップショット、`run.toml` は条件と実行状態。
現行VTK連番だけから物理時刻を推測しない。形状を指定時刻で比較する前に、時刻対応表やPVD等を追加するとよい。

## 7. 参照データと判定基準

[図5のSVG](https://arxiv.org/html/2608.23110v1/rising_bubble_velocity.svg) の描画パスから点列を抽出した。
標準法34点、提案法36点、弱圧縮単独328点。**著者の生の時系列でも、このJuliaコードの計算結果でもない。**

SVG座標の変換は `t=(x-75.6)/5760`、`v=(y-87)/660`。
描画上の縦軸反転前の座標を使用している。端の点は0.07 sをわずかに超えるものがあるため、
参照点は保存しつつ、比較を0～0.07 sへ限定する。

抽出不確かさ0.0005 m/sは、描画曲線の簡略化を考慮した作業上の仮置きであり、著者の保証値ではない。
原データが得られる場合はそちらを優先し、出典とハッシュを更新する。

比較スクリプトの暫定基準：

| 指標 | 基準 |
|---|---|
| 時間重み付きRMS速度誤差／参照最大速度 | 2%以下＋抽出不確かさの寄与 |
| 最大速度誤差／参照最大速度 | 5%以下＋抽出不確かさの寄与 |
| 気体面積の相対変動 | 1e-4以下 |
| 相分率の範囲 | [-1e-3,1+1e-3]内 |
| 投影後の最大発散 × dx／参照速度 | 1e-5以下 |

これらは論文規定値ではなく、作業開始用の判定基準である。
成功時の状態も `velocity_checks_passed_requires_review` であり、再現認定ではない。
基準を変更するときは数値的根拠を説明し、誤差を隠すために緩和しない。

比較スクリプトは256×512、標準法factor=1または提案法factor=30、同じソースハッシュを要求する。
細分化・時間感度の別条件は現行スクリプトで拒否されるため、独立の感度比較処理を追加する。
コードを更新した後に古い結果を比較する場合は、その結果と同じソース版を復元して比較するか、実行版を厳密に識別する仕組みへ改修する。
ハッシュ検査を単に削除して異なる版の結果を混在させない。

格子例は128×256、256×512、512×1024。時間刻みは固定格子で独立に変える。
界面厚さepsilonもdxとともに変わるため、純粋な差分誤差だけを変えているわけではない。
標準法factor=1と0.5、提案法factor=30、15、7.5等の差を評価し、圧力許容誤差の影響も切り分ける。
計算コストが大きければ先に見積もる。収束域を確認せずGCIやRichardson外挿を出さない。

## 8. 気泡上昇合格後：4.4節の実装

多孔質のソルバーはまだない。ここから新規実装する。
出典は論文4.4節、[図10](https://arxiv.org/html/2608.23110v1/initial_settings_porous2D.png) と引用文献の境界処理。

| 項目 | 条件 |
|---|---|
| 領域・格子 | 5 mm × 3 mm、1250 × 750、dx=4 µm |
| 固体 | 直径0.8 mmの円柱、基本間隔1 mmの60°配置 |
| 左側流入 | 液体、3 mm/s |
| 右側流出 | p=0 |
| 上下 | no-slip |
| 液体／気体密度 | 998／1.2 kg/m³ |
| 液体／気体粘度 | 1e-3／9e-6 Pa·s。気泡問題の気体粘度と異なる |
| 表面張力・重力 | 0.072 N/m、重力なし |
| 接触角 | 液体側150° |
| 初期界面 | x=0.5 mm |
| 流動形態の比較 | t=0.18 s |
| 論文の速度比較用計測区間 | t=0.005 sまで。最終流動形態の確認とは別 |

図10から整理した配置は、列番号k=0～4、`x=0.6+sqrt(3)/2*k` mm。
偶数列のyは0,1,2,3 mm、奇数列は0.5,1.5,2.5 mm。
この中心座標の表現は図の寸法・角度からの推定なので、図への重ね合わせで再確認する。
5個の移動は次のとおり。

| 列番号k | 移動前y [mm] | Δy [mm] |
|---:|---:|---:|
| 0 | 2.0 | +0.02 |
| 1 | 1.5 | +0.02 |
| 2 | 2.0 | +0.02 |
| 3 | 1.5 | -0.02 |
| 4 | 1.0 | -0.02 |

実装前に、論文で引用するcut-cell法、immersed boundary法、接触角の固体内外挿を確認する。
必要な作業は流体体積率・開口面積、固体速度条件、圧力係数、接触角・壁近傍曲率、微小cut-cellの安定化である。
単純な格子マスクや接触角なしの計算へ置換して同等と扱わない。

まず固体への漏れ、流量収支、静的接触角、毛管進入圧を検証する。その後、侵入経路と入口出口圧力差、急激な圧力低下を比較する。
図11～13の定量参照は今回抽出していない。追加取得・比較が必要。

毛管時間刻みは論文式と上表から約2.65855e-7 s。0.18 sはその約677,061個分となる。
これは計算量の目安であり実測所要時間ではない。subcyclingは主圧力解法の回数を減らすが、
小ステップ自体は残る。CPU初期版のまま全ケースを開始せず、メモリ・割当・圧力解法のコストを測る。
高速化を行った際は、変更前の小ケースと結果を再比較する。

# 多孔質媒体：検証済み部品と開発状況

**完全な連成二相侵入ソルバーは未実装。論文4.4節の再現結果ではありません。**
保存的な相・運動量の予測更新、粘性力の組込み、弱圧縮の圧力更新を追加しました。
所定流速による相輸送の時間発展は実行済みです。[最新の検証記録](../docs/POROUS_PROGRESS_JA.md)を参照してください。
気泡上昇のレビュー・公開後に開発を開始しました。ユーザーの公開指示により、検証済み部品と開発記録を公開します。完全な二相流ソルバーとしての公開ではありません。

実装・実行した内容：

- 円とセルの交差面積、面の開口率、円弧の面積分。二値マスクではない。
- 小さいcut-cellの保存的な結合。Meyerのmixingそのものではなく、独立したagglomerationという実装選択。
- 固体内の仮想速度と反射点の補間。静止壁の条件を反復で解く。
- 液体側30°・90°・150°の界面外挿。接触角の向きと流体側の不変性を検証。
- 開口率を含む圧力投影、入口速度指定・出口p=0、Galerkin型のマルチグリッド前処理。
- 固体円弧の粘性力。解析的な円柱まわりの接線速度場からのトルクを検査。
- 曲面近傍の流体側3次多項式による曲率再構成。これは対象論文に明記されていない追加の実装選択。

Julia 1.12.7で、部品のテスト71件が合格しました（logs/69-porous-viscous-predictor-tests.log）。
公開済みの気泡ソルバーの49件とは別のテストです。

```bash

```

依存はJulia標準ライブラリのLinearAlgebra、SparseArrays、TOML、SHA、Testです。
検証時はOPENBLAS_NUM_THREADS=1。最新コードと、論文格子の圧力投影に使った当時のコードは
それぞれevidence/porous-20260908へ保存しています。

1250×750、dx=4 µm、図10の18円柱・5個の移動を保った形状で、
単一の単相圧力投影を実行しました。流体面積7.460177631384495e-6 m²、空隙率0.4973451754。
圧力投影は166反復、約2.93秒（前処理構築・JITを含む1回の測定）、割当総量約702 MB。
割当総量はピーク常駐メモリではありません。
入口・出口の相対流量差は7.39e-13、結合した検査体積の最大発散は7.89e-8 s^-1。
これは粘性流や二相流の時間発展を解いた結果ではありません。

曲率の解析検証では、固体内外挿をそのまま2階微分する方式が不適切と分かりました。
流体側再構成後、解析曲率8.333333に対しNX100/200/400で7.65828/8.16759/8.28838。
相対誤差は8.10%/1.99%/0.54%へ減少しました。最細格子の測定接触角は149.685°。
静的な接触液滴を実際に時間発展させた検証ではなく、与えた界面形状に対する境界演算子の検査です。

円柱壁の粘性トルク誤差はNX40/80/160で1.33%/0.832%/0.164%。
こちらも解析速度場を入力した演算子検証であり、Navier–Stokes計算による抗力・トルクの再現ではありません。

残っている作業：相・運動量・粘性・CSF・圧力更新を通した連成とsubcyclingの累積、
静的接触液滴の圧力・寄生流、毛管侵入圧、移動接触線の保存性と時間刻み制約、
論文の0.18秒の侵入形態・入口出口圧力の比較。全CFD実行時間はまだ実測できていません。
単純外挿では毛管substepsが約677061個必要で、最適化と連成後の実測が必要です。
